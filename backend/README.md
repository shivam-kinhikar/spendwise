# SpendWise — AWS Serverless Backend

Production-ready AWS Serverless backend for **SpendWise — Student Expense Tracker**, built with AWS SAM, Node.js 22 (ES modules), Amazon API Gateway HTTP API, Amazon DynamoDB, Amazon Cognito User Pools, and private Amazon S3.

---

## 1. Architectural Highlights

- **Compute**: AWS Lambda running Node.js 22 with ES modules (`.mjs`).
- **API**: Amazon API Gateway HTTP API (v2) with built-in CORS and native Cognito JWT Authorizer.
- **Database**: Amazon DynamoDB Single-Table Design (`SpendWiseTable`) with Pay-Per-Request (On-Demand) billing.
- **Identity & Access**: Amazon Cognito User Pool with web app client (no client secret for browser authentication).
- **Security & Authorization**: User identity (`sub`) is derived strictly on the server from verified JWT claims (`event.requestContext.authorizer.jwt.claims.sub`). Client-provided `userId` parameters in requests are strictly ignored.
- **Receipt Storage**: Amazon S3 bucket with all public access blocked, default AES-256 encryption, and short-lived presigned upload URLs scoped to `receipts/${userId}/...`.
- **Infrastructure as Code**: AWS SAM template (`backend/template.yaml`).

## 2. DynamoDB Single-Table Schema

| Entity | Partition Key (`PK`) | Sort Key (`SK`) | GSI1PK | GSI1SK | Description |
|---|---|---|---|---|---|
| **Transaction** | `USER#<userId>` | `TX#<transactionId>` | `USER#<userId>` | `DATE#<YYYY-MM-DD>#<txId>` | User transaction record. Queryable by month/date via GSI1 without table scans. |
| **Budget** | `USER#<userId>` | `BDG#<YYYY-MM>#<category>` | — | — | Monthly overall or category budget limit. Enforces natural uniqueness. |

## 3. API Contract

Base URL: Generated by AWS SAM stack output (`ApiEndpoint`).

### Public Endpoints
- **`GET /health`**
  - Public health check. No authorization required.
  - Response: `{ "success": true, "data": { "status": "healthy", "service": "spendwise-api", "timestamp": "..." } }`

### Protected Endpoints (Require `Authorization: Bearer <cognito-jwt-access-token>`)

#### Transactions
- **`GET /transactions`**
  - Query parameters: `month` (e.g. `2026-10`), `startDate`, `endDate`, `category`, `type`, `limit`, `nextToken`.
  - Response: `{ "success": true, "data": { "transactions": [...], "nextToken": "...", "count": 10 } }`
- **`GET /transactions/{transactionId}`**
  - Point read. Returns 404 if not found or if owned by another user (prevents ID enumeration).
- **`POST /transactions`**
  - Payload: `{ "description": "Canteen Lunch", "amount": 150.00, "type": "EXPENSE", "category": "Food", "transactionDate": "2026-10-15", "paymentMethod": "UPI", "notes": "Optional" }`
  - Returns 201 Created with generated `transactionId`.
- **`PATCH /transactions/{transactionId}`**
  - Updates only permitted fields on owner's record. Returns 404 if not found.
- **`DELETE /transactions/{transactionId}`**
  - Deletes owner's record with DynamoDB condition expression. Returns 204 No Content.

#### Budgets
- **`GET /budgets?month=YYYY-MM`**
  - Returns user's active budgets for the month.
- **`POST /budgets`**
  - Payload: `{ "month": "2026-10", "category": "OVERALL", "limitAmount": 15000 }`
  - Category can be `"OVERALL"` or any valid expense category (`Food`, `Travel`, `Shopping`, `Education`, `Entertainment`, `Bills`, `Health`, `Other`).
- **`PATCH /budgets/{budgetId}`**
  - Updates budget limit amount.
- **`DELETE /budgets/{budgetId}`**
  - Removes budget limit.

#### Analytics
- **`GET /analytics/summary?month=YYYY-MM`**
  - Computes `totalIncome`, `totalExpenses`, `remainingBudget` (`Limit - Expenses`), `overallBudgetPercentage`, `budgetAlertLevel` (`normal`, `warning_75`, `warning_90`, `exceeded_100`), `categorySpending`, and `previousMonthComparison`.

#### Receipts
- **`POST /uploads/presign`**
  - Payload: `{ "fileName": "bill.jpg", "contentType": "image/jpeg", "transactionId": "tx_123" }`
  - Returns: `{ "success": true, "data": { "uploadUrl": "https://...", "objectKey": "receipts/...", "expiresInSeconds": 300 } }`

## 4. Local Unit Testing

Run unit tests with Node's native test runner:
```bash
cd backend
npm test
```
The test suite runs 33 tests verifying:
- Monetary amount validations, precision limits, and edge cases (NaN, Infinity, negatives).
- Transaction and budget schema validations.
- Cognito JWT claim extraction and rejection of spoofed client-supplied `userId`.
- Remaining budget math (`Limit - Expenses`) and 75%, 90%, 100% threshold calculations.
- API Gateway response envelopes, CORS headers, and error sanitization.

## 5. Deployment Instructions (AWS SAM)

### Prerequisites
1. Install [AWS CLI](https://aws.amazon.com/cli/) and run `aws configure` with your credentials.
2. Install [AWS SAM CLI](https://docs.aws.amazon.com/serverless-application-model/latest/developerguide/install-sam-cli.html).

### Steps
1. **Validate Template**:
   ```bash
   sam validate --lint
   ```
2. **Build Serverless Artifacts**:
   ```bash
   sam build
   ```
3. **Deploy Guided**:
   ```bash
   sam deploy --guided
   ```
   Provide:
   - **Stack Name**: `spendwise-backend`
   - **AWS Region**: `ap-south-1` (or your preferred region)
   - **Parameter Stage**: `dev`
   - **Parameter AllowedOrigin**: `http://localhost:3000` (update to Amplify production domain later)
   - Confirm IAM role creation.

4. **Note Stack Outputs**:
   - `ApiEndpoint` -> Use as `NEXT_PUBLIC_API_BASE_URL` in frontend
   - `CognitoUserPoolId` -> Use as `NEXT_PUBLIC_COGNITO_USER_POOL_ID`
   - `CognitoUserPoolClientId` -> Use as `NEXT_PUBLIC_COGNITO_CLIENT_ID`

## 6. Cost Awareness & Cleanup

All created AWS resources utilize serverless pay-per-request pricing:
- **API Gateway HTTP API**: Free tier covers 1 million calls/month.
- **AWS Lambda**: Free tier covers 1 million requests and 3.2 million seconds of compute time/month.
- **DynamoDB**: Free tier covers 25 GB of storage and 25 write/read capacity units.
- **Cognito**: Free tier covers 50,000 monthly active users.
- **S3**: Free tier covers 5 GB of standard storage.

To delete all cloud resources and prevent charges:
```bash
sam delete --stack-name spendwise-backend
```
